# Supplementary Material

This repository hosts the supplementary material for the undergraduate thesis **"Architecturally Significant Guidelines for Monitoring in MLOps Systems"**, developed at the Institute of Mathematics and Computer Sciences (ICMC), University of São Paulo (USP). It replicates the method of Amou Najafabadi et al. (2026), *Architecturally Significant MLOps Guidelines for ML Model Integration and Deployment: a Gray Literature Review* ([arXiv:2606.06535](https://arxiv.org/abs/2606.06535)), with the scope changed from model integration and deployment to monitoring.

## Contents

| Folder | What it contains |
| --- | --- |
| [`search/`](search/) | Search string, the 66 queries, the search pilot, and the saved Google result pages. |
| [`selection/`](selection/) | All search results, deduplication, the two selection phases, the criteria, and the final list of sources. |
| [`extraction/`](extraction/) | The extraction form. Every candidate excerpt, its validation, and the context of use or trade-off it states. |
| [`synthesis/`](synthesis/) | Coding, codebook, initial guideline statements, and the final guidelines with their sources and descriptions. |

Each folder has its own README that explains the step and the columns of its files.
